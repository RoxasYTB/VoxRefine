# H-shield Implementation Plan

> **For agentic workers:** Execute this plan inline with review checkpoints. Do not reuse G-early-v2 DEV/HOLDOUT metrics to tune H-shield. The G2 HOLDOUT stays sealed permanently.

**Goal:** Test one preregistered, phase-free dereverberation model that learns where attenuation is safe and explicitly protects dry speech activity, weak speech, and onsets.

**Architecture:** Replace G2's gain/phase mask with a bounded attenuation mask and a confidence head: `g = 1 - 0.5*c*sigmoid(a)`, `c = sigmoid(z)`, and phase is fixed to zero. Use the clean source only to create training masks: confidence target 0 on speech-protected bins/frames and 1 on eligible W1 tail; add a direct gain-to-identity guard on protected speech. Keep the same W1/W2, fan-noise, floor, zero, and speech gates as G2; start from a newly frozen, speaker-disjoint source roster.

**Tech Stack:** Python, PyTorch, NumPy, SciPy, existing Cap60 preprocessing and procedural RIR utilities; deterministic GTX 1050 Ti fit/evaluation environment.

## Task 1: Freeze the mechanism on synthetic fixtures

**Status:** Implemented and run twice; deterministic synthetic preflight is NO-GO. The confidence supervision failed its frozen criteria, so Tasks 2–4 were not started. See `docs/benchmarking/h-shield-results-2026-10-10.md`.

- Define confidence labels at STFT resolution by nearest-neighbor mapping of fixed 10 ms frame labels to each STFT hop. Build raw-clean active mask from 20 ms RMS `> 2%` of per-utterance peak, weak mask from active RMS `< 35%` of peak, and onset mask using the evaluator's fixed rising rule. Protect `active ∪ weak ∪ onset`, dilated by one 10 ms frame on both sides. For eligible RIR samples, label W1 as confidence target 1 only where it does not overlap protected speech; all other frames have no confidence target.
- Set confidence targets to 0 on protected bins/frames and 1 on clean W1 bins/frames. Set phase exactly zero. Use `L_conf = mean((c-c*)²)` over only labeled bins/frames; `L_guard = mean(((1-g)/0.5)²)` over protected bins/frames. Preserve current G2 base speech/quiet/fan objective and W1 `tail_loss`; weights are fixed at `λ_conf=1`, `λ_guard=1`, `λ_early=1`, with existing fan coefficient 0.5 every fourth update.
- On protected speech, the direct mask guard supplements waveform losses: desired `g→1`, while W1 confidence targets `c→1` only in eligible tail regions. No loss or label is inferred from DEV or HOLDOUT.
- Synthetic preflight uses the fixed four G2 dry-plus-decaying-tail fixtures and deterministic seeds in memory. It verifies `phase==0`, `0.5<g<1`, finite nonzero gradients for base/W1/confidence/guard terms, `x==0` exact-zero output, `c` near 0 in protected regions and near 1 in eligible W1, and at least 2.5 dB W1 reduction on each fixture after exactly 400 AdamW updates (`lr=2e-4`, `weight_decay=1e-4`). Also require protected-region gain median ≥0.995 and p10 ≥0.98 after fit. Repeat twice and require every non-time numeric metric within `1e-5`.
- Abort before real data preparation if preflight fails. Do not change weights, masks, or thresholds after looking at any real-source result; revise the design under a new experiment ID instead.
