# J-delay-predictor synthetic feasibility plan

## Hypothesis

A causal delayed complex-spectrum predictor can remove predictable late reverberation while preserving current speech better than a same-frame gain mask. It predicts a residual from frames ending 40 ms before the frame being corrected; output is `Y_t = X_t - Rhat_t`.

## Frozen design

- 16 kHz, centered Hann STFT, 512 point FFT, 128 sample hop.
- One-layer unidirectional bias-free GRU, hidden size 128, input real+imaginary STFT frames; bias-free linear 2F complex residual head initialized exactly zero. Bias-free layers preserve exact zero output for an all-zero input after training.
- Delay D=4 frames (32 ms at 128/16k; retain the proposed four-hop delay rather than approximate 40 ms). Effective past context is at least 240 ms. **Note:** this corrects GPT Web's arithmetic: 4×128/16k is 32 ms, not 40 ms. Do not silently alter hop size.
- Eight procedural synthetic TRAIN voices/RIRs and four EVAL voices/RIRs generated by disjoint source parameters and seeds. No corpora or recordings.
- 800 fixed AdamW updates, lr 2e-4, weight decay 1e-4, gradient norm cap 3, deterministic schedule and initialization; two complete runs must match to 1e-5.
- Objective, unit weights: `L = L_W1 + L_active + L_weak + L_onset`. W1 is an energy hinge at 3 dB on 150–300 ms after the known pause. Each speech term is normalized waveform squared error `(Y-X)^2 / (X^2+eps)` on clean-source-derived 20 ms regions. The model is not trained toward a clean target.
- EVAL gates only: every W1 >=2.5 dB and median >=3.0 dB; active p50 [-0.25,+0.25] dB and p10 >-0.75 dB; weak p10 >-1 dB, weak frames below -3 dB <=3%, below -6 dB <=1%; onset p10 >-0.75 dB; W2 (300–450 ms) no fixture <−0.5 dB, median >=0; exact zero invariant; no NaN/Inf; run determinism.
- Diagnostic only: residual RMS/correlation on active, weak, onset, W1. Never tune on EVAL.

## Steps

1. Implement model and frozen synthetic-only auditor.
2. Run two deterministic 800-update passes on the GTX 1050 Ti.
3. Record the result, including NO-GO if any gate fails. Only a PASS would justify planning a fresh speaker-disjoint real-data protocol; no real data is authorized by this preflight.

## Scope

No Adobe parity or generalization claim. Do not inspect `test.wav`, prior DEV/HOLDOUT metrics, or prepare corpus data. Keep checkpoint limited to this plan, model, auditor, and report.
