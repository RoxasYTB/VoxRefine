# G-early Feasibility and Ablation Plan

> **Execution:** run inline in the current Codex task. GPT Web reviewed the G-early design; no training may start before the fresh feasibility pilot passes.

**Goal:** Test whether early reverb at 150–300 ms can be reduced by an E-style attenuation-only model while preserving speech and avoiding late-tail regressions.

**Architecture:** Treat W1 (150–300 ms) as the only supervised tail region. Choose its RIR examples using an input-only dry-relative rule; use deterministic candidate-0 `BASE_ONLY_CONTROL` rows where no candidate qualifies. W2 (300–600 ms) receives no training loss and serves only as an evaluation safety gate. First run a 12-speaker fresh feasibility pilot; only a passing pilot permits new training, DEV, and sealed splits.

**Tech Stack:** Existing Python/PyTorch/NumPy, exact Cap60 preprocessing, procedural RIR generation, LibriSpeech `train-clean-100` and `train-clean-360`.
