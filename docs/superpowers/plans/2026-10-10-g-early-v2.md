# G-early-v2 Implementation Plan

> **For agentic workers:** Execute this plan inline with review checkpoints. Do not reopen or reuse the sealed G-early-v1 HOLDOUT.

**Goal:** Determine whether a trainable, bounded attenuation head can learn early-reverb suppression while preserving speech before spending effort on a new multi-speaker experiment.

**Architecture:** Keep E's zero-preserving complex STFT mask and replace only its saturated gain mapping with `g = 1 - 0.5 * sigmoid(a)`, initialized at `a = -3`. First run deterministic synthetic mechanism checks, including component-gradient measurements and a tiny controlled overfit. Only after those pass may a fully new, speaker-disjoint G-early-v2 dataset and its DEV16/HOLDOUT12 be prepared and frozen.

**Tech Stack:** Python, PyTorch, NumPy, existing E architecture and Cap60 preprocessing.

## Global Constraints

- G-early-v1 is NO-GO on its consumed DEV; its HOLDOUT remains sealed permanently.
- Do not use G-early-v1 TRAIN, DEV, HOLDOUT, or checkpoint outputs to tune or evaluate v2.
- Mechanism checks use deterministic synthetic signals only and create no speaker split.
- v2 TRAIN, DEV16, and HOLDOUT12 use new speakers disjoint from every previously consumed speaker.
- Freeze the v2 model, objective, seeds, gates, evaluator, and source hashes before generating v2 data or opening DEV.
- Keep the same numeric acceptance gates as v1 for direct comparability; HOLDOUT opens only after a passing DEV decision receipt.
- Run v2 training only in the intended fit environment; do not install a large alternate runtime solely to diagnose v1.
- Keep all generated arrays, logs, and checkpoints under ignored `.tools/` paths; publish only reproducible methods and aggregate results.

### Task 3: Add deterministic synthetic mechanism audit

**Files:**
- Create: `scripts/benchmarks/universal_enhancer/compact_dereverb/audit_g_early_v2_mechanics.py`

**Interfaces:**
- Consumes: the isolated v2 model and fixed synthetic dry-plus-decaying-tail fixtures generated in memory.
- Produces: a JSON audit with analytic/autograd checks, per-component gradient norms and cosine, pre-clip norm/clip factor, and tail-only/full-objective overfit results; it must never read `.tools/compact-dereverb/g-early-2026-10-10/`.

- [ ] Use fixed seed `20261010`, four deterministic 3 s harmonic voiced-like signals (f0 103, 127, 149, 181 Hz), a fixed amplitude modulation, and 23 decaying echo taps; known dry targets are generated in memory.
- [ ] At logits `a = -3, 0, +3`, compare autograd with the analytic derivative to relative error `<1e-4`; sweep 10,001 logits on `[-20,+20]` and verify gains stay strictly between 0.5 and 1.
- [ ] Record initial gain-weight mean/std/L2, W1 gain-logit/gain p10/median/p90 per fixture; require each median logit within ±0.05 of −3 and p10/p90 within ±0.10. Require the phase head exactly zero.
- [ ] Verify `y=x` gives `ΔW1=0 dB` and `L_early=1`; check finite, nonzero base and W1 gradients through mask head and trunk for every fixture before any update.
- [ ] Log `||grad_base||`, `||grad_early||`, their cosine, `||grad_total||`, and `min(1, 3 / ||grad_total||)` before clipping.
- [ ] Use `AdamW(lr=2e-4, weight_decay=1e-4)` for exactly 400 updates, cycling fixture index `step % 4`; start tail-only and full-loss fits from identical initial weights.
- [ ] Require every tail-only fixture to improve W1 by at least 2.5 dB; require full-loss median improvement ≥0.5 dB with no fixture regressing by more than 0.25 dB. Record active-speech preservation and W1 median gain/phase changes as mechanism diagnostics, not post-hoc gates.
- [ ] Abort before any v2 real-data preparation if a check fails; record the failure and change only the synthetic mechanism design, not any v1 result.
